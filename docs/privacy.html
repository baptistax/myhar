Privacy Policy for myhar

Last updated: June 3, 2026

myhar is a Chrome extension that generates HAR files from user-provided URLs or user-selected browser tabs and exports them as a ZIP archive.

Single purpose

myhar has one purpose: generate HAR captures from user-provided URLs or user-selected browser tabs and export them as individual HAR files inside one local ZIP archive for debugging, QA, support, troubleshooting, and authorized analysis.

Data handled by the extension

myhar may handle the following data only when the user explicitly starts a capture:

  • URLs and page titles from user-selected tabs or user-provided URLs
  • Web browsing activity related to the selected capture
  • Network requests and responses
  • Request and response headers
  • Cookies and authentication-related headers that may appear in captured network traffic
  • Request and response body content when included in the generated HAR file
  • Site content that appears in captured network responses

HAR files may contain sensitive information depending on the captured website, including cookies, tokens, session identifiers, URLs, headers, request bodies, response bodies, HTML, JSON, text, images, or other site content.

Users should review generated HAR files before sharing them with anyone.

How data is used

The handled data is used only to generate HAR files and package them into a ZIP archive requested by the user.

myhar does not use captured data for analytics, advertising, tracking, profiling, creditworthiness, lending, or any unrelated purpose.

Data storage

myhar generates HAR and ZIP files locally in the browser and downloads them to the user's device.

myhar does not store captured HAR data on external servers.

Data sharing and transfer

myhar does not upload, sell, share, or transfer captured data to any external server or third party.

All generated HAR and ZIP files remain local unless the user manually shares them outside the extension.

Remote code

myhar does not use remote code. All extension code is included in the submitted extension package.

Permissions

myhar uses the tabs permission to list open browser tabs so the user can choose which tabs to capture.

myhar uses the debugger permission to attach to user-selected tabs and capture network activity through the Chrome DevTools Protocol.

myhar uses the downloads permission to save the generated ZIP archive to the user's device.

User control

Capture starts only after a user action. The user chooses either URLs to open and capture or browser tabs to capture. The user can stop a capture and export the ZIP archive.
